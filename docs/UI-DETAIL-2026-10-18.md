## 0. 检查项与方法

检查项（a–i，对齐成熟产品对话界面标准）：

- **a) 消息流视觉**：一次回复=一个连续块（头像/名字一次）；工具 chip / 文件改动 / 用量行对齐头像右侧文本列（左缘对齐，不参差）；气泡间距统一
- **b) 侧栏**：项目/记录两级树的缩进、hover、展开态一致；记录条目 hover 反馈；长标题截断
- **c) 空态**：每个列表/面板无数据有明确空态说明（非空白/永转 spinner）
- **d) 加载/错误态**：异步有 loading；按钮防连点；失败可见且是人话
- **e) 文案**：tooltip / placeholder / 按钮措辞与行为一致，无过时文案
- **f) 深浅主题**：`.css` 裸写颜色（`grep #[0-9a-fA-F]{3,6}` 排除 theme 变量定义处）改主题变量
- **g) 间距/字号体系**：用 `--sp-*` / 字号变量，不用魔数（明显不一致处才改，不做全局风暴）
- **h) 一致性**：同类操作按钮样式/措辞统一；图标语义一致
- **i) 键盘**：对话框 Esc；焦点可见

方法：逐文件读源码 + 全局 grep 反模式（`原生控件`、`裸色`、`未定义主题变量`、`alert/confirm`、`暂无` 空态覆盖、`Esc` 处理），并对已修项做代码审查验证。

分类标记：

- **已修**：前序阶段（含 10-17 审计 31 项、本轮截图暴露问题）已完成，本轮仅做验证确认。
- **本轮修**：本轮发现并直接修正。
- **建议不动**：审查后判定当前实现已达标或改动风险/收益不合理，附理由。
