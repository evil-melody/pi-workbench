# alignments/ —— 历史对齐记录（归档）

本目录是项目早期「逐项对齐 + 验证」阶段的工作记录，按序号保留，仅作历史查阅。

## 阅读须知

- **这些文档描述的是当时的中间状态**，不是当前实现。当前结构以
  [../ARCHITECTURE.md](../ARCHITECTURE.md)、[../AGENT-OPS.md](../AGENT-OPS.md)、
  [../PAGE-FUNCTION-AUDIT.md](../PAGE-FUNCTION-AUDIT.md) 为准。
- 文档里出现的「参考基线」指立项时对照的外部产品能力清单，**本仓不依赖它、也不搬运其代码**。
- 按「本项目是独立项目」的命名要求，历史文档中指向外部仓库 / 包的标识已做去标识化处理
  （例如截图名、包名、克隆路径统一改写为中性表述），因此个别处的**原始出处无法从文中复原**。
  需要原始出处时，请查版本历史而不是这些文档。
