## 二、机制落地

- vue-i18n runtime-only（`legacy: false`），key 为中文原文；同字不同义用 `@context` 后缀区分，
  展示时 `stripContext()` 剥离。
- 翻译按领域拆包：`common / chat / library / projects / settings / memory / experiments / errors`，
  单文件均远低于 2000 行。
- 缺英文时 `t()` 自实现 `interpolate` 回退中文源文，不经过 vue-i18n 的 key 查找，
  因此任何中间状态都不会暴露 raw key。
- 语言解析：settings.json（权威）> `navigator.language` > `zh-CN`；localStorage
  `pi-workbench:lang` 只做首屏缓存；`index.html` 内联脚本同步 `<html lang>`，避免闪中文。
- 切换语言不重启内核：前端全部走响应式 `t()`；托盘通过 `tray_relocalize` 原地 `set_text`。
- 日期时间走 `Intl.DateTimeFormat`（`src/i18n/format.ts`）；相对时间保留原实现查词条。

## 三、仍是中文兜底的部分

以下位置当前会显示中文原文，属于已确认的「允许回退」范围：

1. **后端错误 `detail` 原文**。后端存量命令以字符串返回错误，其中不少仍是中文 `format!` 串。
   前端 `describeIpcError` 先按约定解析 `code` / `code: detail` 查词条（已覆盖 46 个高频码），
   查不到才原样展示 `detail`。未错误码化的低频命令因此保持中文兜底。
2. **`TOOL_PENDING`（「调用工具」）**。工具 chip 的瞬时占位文案在模块加载时求值，
   语言切换后新产生的占位仍取加载时语言；真实工具名到达后立即回填，可见时长以毫秒计。
3. **模型提示词**。`PLAN_INSTRUCTION`、`buildExecPrompt`、`ATTACHMENT_MARKER` 保持中文，
   已加 `i18n-ignore` 标注：属于模型输入，翻译会改变行为并破坏 journal 回放解析。
4. **扩展一期未动**。扩展目录下的提示文案未抽取，按既定口径留待二期。
5. **Rust 托盘/通知的少量状态串**。菜单、tooltip、任务完成/失败通知标题已接入
   `crate::i18n`；其余后台状态文案未逐条抽出。
6. **非界面字符串**。开发者日志、正则模式、历史持久化值（旧版思考档位中文值）已按
   `i18n-ignore` 豁免，不计入残留。
